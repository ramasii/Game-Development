## 🎯 Apa Ini?
Sistem dasar pengukuran jarak antar nada dalam musik barat menggunakan **semitone** sebagai satuan terkecil — fondasi wajib sebelum bisa memahami dan menggunakan Chord Relationships (CR). Gunakan skill ini saat pertama kali belajar teori musik, atau saat membaca notasi interval dalam CR Reference.

**Kapan digunakan:**
- Sebelum membaca atau menggunakan [[Chord Relationship (CR) Framework]].
- Saat bingung mengapa dua nada terdengar harmonis atau disonan.
- Saat membangun akor dari nol di FL Studio dan perlu tahu jarak antar nada yang benar.

## 🧠 Poin Penting

### Semitone & Whole Tone
- **Semitone** = jarak terkecil dalam musik barat — jarak antara dua tuts piano yang bersebelahan (baik hitam maupun putih).
- **Whole Tone** = 2 semitone.

> Di piano: C → C# = 1 semitone. C → D = 2 semitone (1 whole tone). Ini berlaku universal untuk semua instrumen.

### 12 Interval dalam Satu Oktaf

| Interval | Simbol | Jumlah Semitone | Contoh dari C |
|---|---|---|---|
| minor 2nd | ii | 1 | C → C# |
| Major 2nd | II | 2 | C → D |
| minor 3rd | iii | 3 | C → D# |
| Major 3rd | III | 4 | C → E |
| Perfect 4th | IV | 5 | C → F |
| Tritone / Aug. 4th | IV+ | 6 | C → F# |
| Perfect 5th | V | 7 | C → G |
| minor 6th | vi | 8 | C → G# |
| Major 6th | VI | 9 | C → A |
| minor 7th | vii | 10 | C → A# |
| Major 7th | VII | 11 | C → B |
| Octave | 8 | 12 | C → C (tinggi) |

> **Huruf kecil** (ii, iii, iv...) = interval minor/kecil. **Huruf besar** (II, III, IV...) = interval Major/besar. Ini penting karena notasi yang sama dipakai di sistem CR.

### Interval Berdasarkan "Karakter Suara"

| Karakter | Interval | Keterangan |
|---|---|---|
| **Sangat stabil** | IV, V, 8 | Terdengar "sempurna", damai |
| **Stabil tapi berwarna** | III, VI | Manis, hangat |
| **Tegang ringan** | II, vii | Sedikit tidak puas, minta resolusi |
| **Tegang kuat** | ii, VII | Lebih disonan, menarik perhatian |
| **Paling disonan** | IV+ (Tritone) | Paling tidak stabil — efek "menggantung" dan asing |

### Root Note & Cara Menghitung Interval
Interval selalu dihitung dari **root note** (nada dasar akor — misal: "C" di "C Major", "A" di "A minor"). Untuk menemukan nada target dari sebuah interval: hitung semitone ke atas dari root note.

> Contoh: Root = C, interval = III (4 semitone) → C(0) → C#(1) → D(2) → D#(3) → E(4) = **E**. Jadi interval III dari C adalah E.

## 🛠️ Cara Pakai di FL Studio
1. Buka Piano Roll di FL Studio.
2. Tentukan root note akor pertama (misal: C).
3. Hitung target nada menggunakan tabel di atas sesuai interval yang diinginkan.
4. Nada target = root note akor kedua yang akan dibuat.
5. Gunakan [[Chord Relationship (CR) Framework]] untuk menentukan interval + tipe akor yang sesuai emosi yang diinginkan.
